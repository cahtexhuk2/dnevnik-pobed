# Дневник Побед MVP

Браузерный прототип личного дневника побед, трекера привычек и раздела "Тень".

## Запуск

```bash
python3 -m http.server 8000
```

Открыть в браузере:

```text
http://localhost:8000
```

## Что уже есть

- вкладка "Сегодня" с простыми и составными привычками;
- составная привычка "Подмасадана / духовные практики";
- стена побед с ручным добавлением и загрузкой фото;
- вкладка "Прогресс" с сериями и достижениями;
- вкладка "Тень";
- превращение записи из "Тени" в победу;
- локальное сохранение данных в браузере через `localStorage`;
- адаптивный интерфейс под телефон и компьютер.

## Ограничения MVP

- данные пока хранятся только в текущем браузере;
- фото сохраняются как base64 в `localStorage`, поэтому для долгой реальной эксплуатации нужно будет вынести хранение в базу/облако;
- логин, синхронизация между устройствами и доступ для друзей будут следующим этапом.
