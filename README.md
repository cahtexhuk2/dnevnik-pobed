# Дневник Побед MVP

Браузерный прототип личного дневника побед, трекера привычек и раздела "Тень".

## Запуск

```bash
python3 -m http.server 8000
```

Открыть в браузере:

```text
http://localhost:8000
```

Для подготовки серверного режима скопировать пример конфига:

```bash
cp config.example.js config.js
```

## Что уже есть

- вкладка "Сегодня" с простыми и составными привычками;
- составная привычка "Подмасадана / духовные практики";
- стена побед с ручным добавлением и загрузкой фото;
- вкладка "Прогресс" с сериями и достижениями;
- вкладка "Тень";
- превращение записи из "Тени" в победу;
- экран "Профиль" с Supabase-входом, аватаркой и личными данными;
- экспорт локальных данных в JSON;
- Supabase SQL-схема для будущих логинов, профилей и хранения фото;
- Supabase Auth для регистрации и входа;
- синхронизация профиля, привычек и ежедневных галочек через Supabase;
- локальное сохранение как резервный режим через `localStorage`;
- честный прогресс: прошлые дни не заполняются автоматически;
- адаптивный интерфейс под телефон и компьютер.

## Ограничения MVP

- профиль, привычки и галочки уже синхронизируются через Supabase;
- фото до 1.8 МБ сохраняются как base64 в `localStorage`, поэтому для долгой реальной эксплуатации нужно будет вынести хранение в базу/облако и добавить сжатие;
- победы и "Тень" пока локальные, их синхронизация будет следующим этапом;
- фото пока не загружаются в Supabase Storage.

## Supabase

Файл `supabase/schema.sql` создает таблицы профилей, привычек, отметок, побед, "Тени", настроек и bucket `victory-media` для изображений. Подробная инструкция лежит в `supabase/README.md`.
